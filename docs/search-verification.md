## Same-agent security review

Reviewed entry points: semantic tool arguments, owner/session lifecycle, local file bytes/path metadata, native classifier responses and result cursors. Reviewed flows through semantic validation/execution/parents/results, Pi owner/lifecycle/tool wrappers and the existing filesystem capturer/source/process policy. No HTTP surface is introduced.

- **Spoofing / elevation:** caller roots, priorities and unknown authority fields reject. Host context alone supplies root/exclusions; authorizing the semantic family precedes acquisition and persistence precedes dispatch. Record provenance cannot invoke current-file reads. Owned evidence IDs are checked against the selected parent.
- **Tampering:** captured bytes and identities remain frozen across continuation and cutoff views. Model output supplies judgments, never locations. HMAC cursors bind parent, runtime secret, revision, policy and limit; modified or cross-parent cursors reject. Current-source checks cannot replace historical evidence.
- **Repudiation:** existing append-only all-branch liability remains authoritative. Release, cancellation and navigation cannot refund attempts; unknown dispatched usage stays charged. This is not tamper-proof storage against a malicious local operator editing session files.
- **Disclosure:** source content is transmitted only through explicit authorized execution; diagnostics use stable sanitized codes. Normal tool results/transcripts still contain evidence. Built-in exclusions are heuristics, not exhaustive secret detection. Windows/Git workers use bounded fixed operations and sanitized environments; no caller shell program is accepted.
- **Denial of service:** bounded request inputs, file enumeration/windows, subprocess output/timeouts, parent/batch/memory quotas and response caps limit work. Capture and owned reads propagate caller/disable cancellation and drain before release. Audit tests reproduced ignored cancellation in current-file reads; the wrapper, read lease and capture now carry a normalized abort signal, with expiry still taking precedence. Pre-aborted capture now avoids metadata I/O; owned deadlines retain deadline classification. Unknown accounting stops conservatively rather than granting free work.

No unresolved actionable security defect was identified in this scoped review. Informational residual risks: malicious concurrent filesystem mutation is outside an OS-sandbox guarantee; user-installed Git/PowerShell and host extensions are trusted;8MiB accounting does not cap total transient JavaScript heap; live relevance accuracy and provider behavior are not proven by fake responses. These are explicit limitations, not waived functional requirements.
